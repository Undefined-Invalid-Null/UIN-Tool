## 一、应用概述

UIN Tool 是一个轻量级的插件化框架应用，允许您动态加载和运行第三方插件。v4.4.4 版本统一了插件弹窗系统并修复了插件交互问题。v4.4.0 版本新增了**插件数据持久化存储**和**权限系统完善**。

### 1.1 核心功能

| 功能模块 | 说明 |
|----------|------|
| 插件系统 | 支持原生插件（Java/Kotlin）和 Web 插件（HTML/CSS/JS） |
| 数据持久化 | 每个插件独立的 data/ 目录，更新时自动保留用户数据 |
| 终端环境 | 内置基于 Termux 的完整 Linux 终端 |
| 后端集成 | Web 插件可启动 Python/Node.js/PHP/二进制后端 |
| 插件仓库 | 从 GitHub 官方仓库浏览、搜索和安装插件 |
| 开发工具 | 插件创建向导、代码编辑器（Sora Editor）、模板导出 |
| 权限管理 | 应用权限和插件独立权限管理，状态持久化 |
| 备份恢复 | 备份/恢复所有插件和配置 |
| UI 个性化 | 38+ 颜色项、7 种圆角、完整颜色选择器 |
| 文档中心 | 开发文档、使用帮助、更新日志、关于信息 |
| 桌面小部件 | 列表小部件（3x3）和 1x1 快捷方式 |

### 1.2 插件类型对比

| 特性 | 原生插件 | Web 插件 |
|------|----------|----------|
| 开发语言 | Kotlin/Java | HTML/CSS/JS |
| 性能 | 最优 | 良好 |
| 热更新 | 需重新编译 | 无需编译 |
| 开发门槛 | 较高 | 较低 |
| 系统 API 访问 | 完全访问 | 通过 JS 接口（140+ API） |
| 数据存储 | PluginContext API | UINPlugin 存储 API |
| 后端支持 | 无 | Python/Node.js/PHP/二进制 |

## 二、首次启动

### 2.1 启动流程

用户点击图标 → 权限检查 → SplashActivity (启动页) → 检查首次启动
├── 是 → OnboardingActivity (引导页) → MainActivity
└── 否 → MainActivity

### 2.2 权限请求

首次启动时，应用会请求存储权限：

1. 显示权限说明对话框
2. 点击「去授权」跳转到系统设置
3. 授予权限后自动返回应用
4. 如果拒绝权限，应用会退出

### 2.3 引导页

首次安装或版本更新时，会自动显示引导页：

| 页面 | 内容 |
|------|------|
| 第1页 | 欢迎语 / 版本更新说明 |
| 第2页 | 插件管理功能介绍 |
| 第3页 | 插件开发工具介绍 |
| 第4页 | Web 插件支持介绍 |
| 第5页 | 准备就绪，开始体验 |

操作方式：
- 点击「下一步」翻页
- 点击「跳过」直接进入主界面
- 最后一页点击「开始体验」

六、自动更新

6.1 启动自动检测

每次启动应用时，系统会自动检查 GitHub 最新版本。

6.2 强制更新机制

当 Release Tag 格式为 {版本代码}-{版本名称}-1 时，会强制用户更新：

Tag 格式 示例 强制更新
x-y-z 且 z=1 2-1.0.1-1 ✅ 是
x-y-z 且 z=0 2-1.0.1-0 ❌ 否
x-y 2-1.0.1 ❌ 否

强制更新特点：

· 弹窗中「暂不更新」按钮被隐藏
· 用户必须选择「自动下载」或「手动下载」

6.3 更新选项

选项 说明
自动下载 在应用内下载 APK，完成后直接安装
手动下载 打开浏览器跳转到 GitHub Releases 页面
暂不更新 关闭对话框（普通更新可用）
忽略此版本 记录忽略的版本，下次不再提示

十、插件管理

10.1 插件格式说明

插件文件扩展名为 .tpk，本质上是 ZIP 压缩包。

原生插件结构：

```
plugin.tpk
├── plugin.json      # 插件配置文件
├── icon.png         # 插件图标 (建议 128x128)
├── plugin.dex       # 编译后的 DEX 文件
├── src/             # 源码目录
└── res/             # 资源文件目录
```

Web 插件结构：

```
plugin.tpk
├── plugin.json      # 插件配置文件
├── icon.png         # 插件图标
├── web/             # Web 资源目录
│   ├── index.html   # 入口页面 (必须)
│   ├── style.css    # 样式文件 (可选)
│   └── script.js    # JavaScript 文件 (可选)
├── data/            # ✅ 插件数据目录（运行时创建）
└── cache/           # ✅ 插件缓存目录（运行时创建）
```

10.2 plugin.json 配置说明

```json
{
    "pluginId": "com.example.myplugin",
    "version": 1,
    "versionName": "1.0.0",
    "minHostVersion": 1,
    "name": "我的插件",
    "author": "开发者",
    "description": "插件描述",
    "notice": "欢迎使用！首次打开会显示此说明",
    "icon": "icon.png",
    "mainClass": "com.example.MainPlugin",
    "apiLevel": 21,
    "uiType": "native",
    "entry": "web/index.html",
    "permissions": ["INTERNET", "VIBRATE"],
    "backend": "python",
    "backendPort": 8000,
    "backendEntry": "scripts/backend/server.py"
}
```

10.3 导入插件

方式 说明
单文件导入 选择单个 .tpk 文件
批量导入 选择多个 .tpk 文件
插件集导入 选择包含多个 .tpk 的 ZIP 包

十一、插件开发

11.1 创建插件

1. 点击底部「开发」标签
2. 点击「创建插件」
3. 选择前端类型：
   · 原生 UI：Android View 原生界面
   · 纯 WebView：仅 HTML/CSS/JS，无后端
   · WebView + 后端：HTML/CSS/JS + 后端服务
4. 如选择 WebView + 后端，选择后端语言：
   · Python
   · Node.js
   · PHP
   · 二进制文件
5. 按照向导填写插件信息
6. 点击「完成」生成项目文件

11.2 向导步骤说明

类型 步骤数 步骤内容
原生 UI 5 步 配置 → 图标 → 代码 → 资源 → 打包
纯 WebView 4 步 配置 → 图标 → Web代码 → 打包
Web + 后端 5 步 配置 → 图标 → 代码 → 资源 → 打包
Web + 二进制后端 4 步 配置 → 图标 → 选择文件 → 打包

11.3 插件说明功能

在 plugin.json 中添加 notice 字段：

```json
{
    "notice": "欢迎使用我的插件！\n\n功能说明：\n1. 点击按钮执行操作\n2. 数据自动保存\n\n注意事项：\n- 需要存储权限\n- 首次使用请先配置"
}
```

首次打开插件时，会自动显示说明弹窗，用户可选择：

· 「知道了」：关闭弹窗，不再显示（本次会话）
· 「不再提示」：永久关闭该插件的说明
· 「稍后提醒」：关闭弹窗，下次打开再次显示

11.5 插件数据持久化存储

v4.4.0 新增功能

每个插件拥有独立的数据存储空间，数据在插件更新时自动保留。

Web 插件存储 API：

```javascript

UINPlugin.setStorageInt('score', 100);

// 批量操作
UINPlugin.setStorageBatch(JSON.stringify({k1:'v1', k2:'v2'}));

// 文件操作

const content = UINPlugin.readFile('notes.txt');
UINPlugin.deleteFile('notes.txt');

// 数据统计
const stats = JSON.parse(UINPlugin.getStorageStats());

// 导入导出
const exported = UINPlugin.exportData();
UINPlugin.importData(exported);
```

原生插件存储 API：


十八、常见问题

Q1: 如何获取更多插件？
A: 从「仓库」页面安装官方插件，或自己开发插件。

Q2: 插件安全吗？
A: 插件导入时进行 SHA-256 签名验证，插件权限独立控制。建议只从可信来源获取插件。

Q3: 工作目录在哪里？
A: 默认路径：/storage/emulated/0/UIN_Tool/

Q4: 终端功能如何使用？
A: 点击「开发」→「打开终端」，首次使用会自动安装 Linux 环境。

Q5: 原生插件编译失败？
A: 当前原生插件编译功能暂时禁用（Android 环境缺少 tools.jar 支持），建议使用 Web 插件或 PC 端编译。

Q6: Web 插件修改后不生效？
A: 关闭并重新打开插件即可，无需重新编译。

Q7: 插件权限如何管理？
A: 插件在 plugin.json 中声明权限，启动前自动检查并请求。

Q8: 应用闪退怎么办？
A: 重新打开应用（会自动显示崩溃日志），查看运行日志分析原因，或清除应用数据重装。

Q9: 如何自定义 UI 颜色？
A: 在「管理」→「UI 个性化」中调整颜色配置。

Q10: 如何更新 UIN Tool？
A: 启动自动检测新版本，或在「管理」→「检查更新」中手动检查。

Q11: 仓库页面加载失败？
A: 检查网络连接，下拉刷新重试，在「GitHub 加速」中配置镜像站。

Q12: 下载插件速度慢？
A: 在「GitHub 加速」中启用 CDN 加速，勾选更多的镜像站。

Q13: 小部件不显示插件？
A: 检查小部件是否已配置插件，尝试重新配置，刷新小部件列表。

Q14: 首次启动有引导页吗？
A: 首次安装或版本更新时会自动显示引导页。

Q15: 长按应用图标没有快捷方式？
A: 需要 Android 7.1+ 系统，部分第三方启动器可能不支持。

Q16: 什么是强制更新？
A: 当 Release Tag 格式为 {版本代码}-{版本名称}-1 时，会强制用户更新，无法跳过。

Q17: 如何导出开发模板？
A: 在「开发」页面点击「导出模板」，系统自动生成到工作目录。

Q18: 图标着色开关有什么用？
A: 开启后所有图标使用主题色着色；关闭后图标保持原色。

Q19: 如何恢复 UI 配置？
A: 在「UI 个性化」中点击「重置」按钮。

Q20: 如何查看版本更新内容？
A: 点击「管理」→「文档中心」→「更新日志」

Q21: 如何创建带后端的 Web 插件？
A: 点击「创建插件」→ 选择「WebView + 后端」→ 选择后端语言（Python/Node.js/PHP/二进制）。

Q22: Python 后端需要安装什么？
A: 使用 Python 内置的 http.server，无需安装 Flask 等第三方库。

Q23: 插件说明功能如何使用？
A: 在 plugin.json 中添加 notice 字段，首次打开时自动显示。

Q24: 代码编辑器支持哪些语言？
A: 支持 30+ 种编程语言，包括 Java、Kotlin、Python、JavaScript、TypeScript、HTML、CSS、JSON、XML、Markdown、Shell、SQL、Go、Rust、PHP、Ruby、Swift、Dart、Lua、Scala、Perl、Haskell、Elixir、Erlang、Clojure、Groovy、Dockerfile、Makefile、INI、Properties、TOML、YAML 等。

Q25: 插件数据存储在哪里？
A: 插件数据存储在 /storage/emulated/0/UIN_Tool/plugins/{pluginId}/data/ 目录，KV 数据存储在 SharedPreferences 中。更新插件时数据自动保留。

Q26: 如何清除插件数据？
A: Web 插件可使用 UINPlugin.clearStorage() 和 UINPlugin.clearCache()，或在「插件管理」中卸载插件。

Q27: 权限状态会持久化吗？
A: 会。一次授权后，权限状态永久保存，下次打开不再重复弹窗。

Q28: 如何重置插件权限状态？
A: 清除应用数据，或在开发者选项中重置权限状态。
