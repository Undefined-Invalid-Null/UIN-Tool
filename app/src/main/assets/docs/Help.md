## 一、应用概述

UIN Tool 是一个轻量级的插件化框架，允许您动态加载和运行第三方插件。v4.0.0 版本基于 Kotlin + Jetpack Compose 完全重构，带来了现代化的 UI 体验。

### 核心功能

| 功能模块 | 说明 |
|----------|------|
| 🚀 插件系统 | 支持原生插件（Java/Kotlin）和 Web 插件（HTML/CSS/JS） |
| 🖥️ 终端环境 | 内置基于 Termux 的完整 Linux 终端 |
| 📦 插件仓库 | 从 GitHub 官方仓库浏览、搜索和安装插件 |
| 🛠️ 开发工具 | 插件创建向导、代码编辑器、模板导出 |
| 🔐 权限管理 | 应用权限和插件独立权限管理，含权限说明 |
| 💾 备份恢复 | 备份/恢复所有插件和配置 |
| 🎨 UI 个性化 | 38+ 颜色项、7 种圆角、完整颜色选择器 |
| 📚 文档中心 | 开发文档、使用帮助、更新日志、关于信息 |
| 🖥️ 桌面小部件 | 列表小部件（3x3）和 1x1 快捷方式 |

### 插件类型对比

| 特性 | 原生插件 | Web 插件 |
|------|----------|----------|
| 开发语言 | Kotlin/Java | HTML/CSS/JS |
| 性能 | 最优 | 良好 |
| 热更新 | 需重新编译 | 无需编译 |
| 开发门槛 | 较高 | 较低 |
| 系统 API 访问 | 完全访问 | 通过 JS 接口 |

## 二、首次启动

### 启动流程

```

用户点击图标 → 权限检查 → SplashActivity (启动页) → 检查首次启动
├── 是 → OnboardingActivity (引导页) → MainActivity
└── 否 → MainActivity

```

### 权限请求

首次启动时，应用会请求存储权限：

1. 显示权限说明对话框，解释为什么需要存储权限
2. 点击「去授权」跳转到系统设置
3. 授予权限后自动返回应用
4. 如果拒绝权限，应用会退出

### 引导页 (OnboardingActivity)

首次安装或版本更新时，会自动显示引导页：

| 页面 | 内容 |
|------|------|
| 第1页 | 欢迎语 / 版本更新说明 |
| 第2页 | 插件管理功能介绍 |
| 第3页 | 插件开发工具介绍 |
| 第4页 | Web 插件支持介绍 |
| 第5页 | 准备就绪，开始体验 |

**操作方式：**

- 点击「下一步」翻页
- 点击「跳过」直接进入主界面
- 最后一页点击「开始体验」

## 五、终端功能（基于 Termux）

> 🔥 **v4.0.0 新增功能**：UIN Tool 内置完整的终端环境，核心引擎基于 Termux 改编。

### 访问方式

1. 点击底部「开发」标签
2. 点击「打开终端」按钮
3. 首次使用会自动安装 Linux 环境

### 终端特性

| 特性 | 说明 |
|------|------|
| Shell 支持 | bash、zsh、fish 等主流 Shell |
| 包管理器 | APT (Debian/Ubuntu 软件源) |
| 开发工具 | gcc、clang、make、git 等 |
| 脚本语言 | Python、Node.js、Ruby、Perl 等 |
| 文本编辑器 | vim、nano、emacs 等 |
| 网络工具 | curl、wget、openssh 等 |
| 多会话 | 支持多个终端会话同时运行 |
| 多窗口 | Android 7.0+ 多窗口支持 |
| 自定义快捷键 | 可配置的硬件/软件键盘快捷键 |

### 常用命令

```bash
# 更新软件源
pkg update

# 安装 Python
pkg install python

# 安装 Node.js
pkg install nodejs

# 安装 git
pkg install git

# SSH 连接服务器
ssh user@hostname

# 查看存储目录
ls ~/storage/shared/
```

终端设置

1. 点击「终端设置」按钮
2. 可配置：
   · 终端字体大小和样式
   · 配色方案
   · 键盘快捷键
   · 额外功能按键

六、自动更新

启动自动检测

每次启动应用时，系统会自动检查 GitHub 最新版本。

强制更新机制

当 Release Tag 格式为 {版本代码}-{版本名称}-1 时，会强制用户更新：

Tag 格式 示例 强制更新
x-y-z 且 z=1 2-1.0.1-1 ✅ 是
x-y-z 且 z=0 2-1.0.1-0 ❌ 否
x-y 2-1.0.1 ❌ 否

强制更新特点：

· 弹窗中「暂不更新」按钮被隐藏
· 用户必须选择「自动下载」或「手动下载」

更新选项

选项 说明
自动下载 在应用内下载 APK，完成后直接安装
手动下载 打开浏览器跳转到 GitHub Releases 页面
暂不更新 关闭对话框（普通更新可用）
忽略此版本 记录忽略的版本，下次不再提示

十、插件管理

插件格式说明

插件文件扩展名为 .tpk，本质上是 ZIP 压缩包。

原生插件结构

```
plugin.tpk
├── plugin.json      # 插件配置文件
├── icon.png         # 插件图标 (建议 128x128)
├── plugin.dex       # 编译后的 DEX 文件
├── src/             # 源码目录
└── res/             # 资源文件目录
```

Web 插件结构

```
plugin.tpk
├── plugin.json      # 插件配置文件
├── icon.png         # 插件图标
└── web/             # Web 资源目录
    ├── index.html   # 入口页面 (必须)
    ├── style.css    # 样式文件 (可选)
    └── script.js    # JavaScript 文件 (可选)
```

plugin.json 配置说明

```json
{
    "pluginId": "com.example.myplugin",
    "version": 1,
    "versionName": "1.0.0",
    "minHostVersion": 1,
    "name": "我的插件",
    "author": "开发者",
    "description": "插件描述",
    "icon": "icon.png",
    "mainClass": "com.example.MainPlugin",
    "apiLevel": 21,
    "uiType": "native",
    "entry": "web/index.html",
    "permissions": ["INTERNET", "VIBRATE"]
}
```

导入插件

方式 说明
单文件导入 选择单个 .tpk 文件
批量导入 选择多个 .tpk 文件
插件集导入 选择包含多个 .tpk 的 ZIP 包

导出插件

1. 勾选要导出的插件（支持多选）
2. 点击「导出」按钮
3. 插件被打包为 ZIP 文件

卸载插件

十一、插件开发

创建原生插件

1. 点击「开发」→「创建原生插件」
2. 填写插件信息：
   · 插件ID：域名倒序格式
   · 插件名称：显示名称
   · 主类名：完整包名+类名
3. 选择插件图标
4. 编写 Kotlin/Java 代码
5. 生成项目文件

⚠️ 注意：当前原生插件编译功能暂时禁用，建议使用 Web 插件或 PC 端编译。

创建 Web 插件

1. 点击「开发」→「创建 Web 插件」
2. 选择模板类型：
   · 完整模板：生成示例 HTML/CSS/JS
   · 空白模板：生成基础框架
   · 导入已有项目：导入 ZIP 包
   · 跳过：只创建空目录
3. 填写插件信息
4. 编写 HTML/CSS/JS
5. 生成项目文件

Web 插件 JavaScript API

```javascript
// 调用宿主功能
UINPlugin.callHost('toast', '消息');
UINPlugin.callHost('finish', '');
UINPlugin.callHost('vibrate', '200');

// HTTP 请求
UINPlugin.httpGet(url, callbackId);
UINPlugin.httpPost(url, data, callbackId);

// 传感器
UINPlugin.startSensor('accelerometer', callbackId);
UINPlugin.stopSensor();

// 文件系统
UINPlugin.writeFile('test.txt', '内容');
UINPlugin.readFile('test.txt');
UINPlugin.listFiles('');

// 存储
UINPlugin.setStorage('key', 'value');
UINPlugin.getStorage('key');
UINPlugin.clearStorage();
```

插件权限管理

插件在 plugin.json 中声明所需权限：

```json
{
    "permissions": [
        "android.permission.INTERNET",
        "android.permission.VIBRATE"
    ]
}
```

权限请求流程：

1. 插件安装时记录权限声明
2. 启动时自动检查权限状态
3. 缺失权限时显示说明对话框
4. 分组请求权限
5. 权限授予后加载插件

十八、常见问题

Q1: 如何获取更多插件？

· 📦 从「仓库」页面安装官方插件
· 🔧 自己开发插件
· 👥 社区分享

Q2: 插件安全吗？

· ✅ 插件导入时进行 SHA-256 签名验证
· ✅ 插件权限独立控制
· ⚠️ 建议只从可信来源获取插件

Q3: 工作目录在哪里？

默认路径：/storage/emulated/0/UIN_Tool/

Q4: 终端功能如何使用？

点击「开发」→「打开终端」，首次使用会自动安装 Linux 环境。

Q5: 原生插件编译失败？

当前原生插件编译功能暂时禁用（Android 环境缺少 tools.jar 支持），建议使用 Web 插件或 PC 端编译。

Q6: Web 插件修改后不生效？

关闭并重新打开插件即可，无需重新编译。

Q7: 插件权限如何管理？

插件在 plugin.json 中声明权限，启动前自动检查并请求。

Q8: 应用闪退怎么办？

1. 重新打开应用（会自动显示崩溃日志）
2. 查看运行日志分析原因
3. 清除应用数据或重装

Q9: 如何自定义 UI 颜色？

在「管理」→「UI 个性化」中调整颜色配置。

Q10: 如何更新 UIN Tool？

· 启动自动检测新版本
· 或在「管理」→「检查更新」中手动检查

Q11: 仓库页面加载失败？

· 检查网络连接
· 下拉刷新重试
· 在「GitHub 加速」中配置镜像站

Q12: 下载插件速度慢？

· 在「GitHub 加速」中启用 CDN 加速
· 勾选更多的镜像站
· 尝试切换网络

Q13: 小部件不显示插件？

· 检查小部件是否已配置插件
· 尝试重新配置
· 刷新小部件列表

Q14: 首次启动有引导页吗？

是的，首次安装或版本更新时会自动显示引导页。

Q15: 长按应用图标没有快捷方式？

· 需要 Android 7.1+ 系统
· 部分第三方启动器可能不支持

Q16: 什么是强制更新？

当 Release Tag 格式为 {版本代码}-{版本名称}-1 时，会强制用户更新，无法跳过。

Q17: 如何导出开发模板？

在「开发」页面点击「导出模板」，系统自动生成到工作目录。

Q18: 图标着色开关有什么用？

开启后所有图标使用主题色着色；关闭后图标保持原色。

Q19: 如何恢复 UI 配置？

在「UI 个性化」中点击「重置」按钮。

Q20: 如何查看版本更新内容？

点击「管理」→「文档中心」→「更新日志」
