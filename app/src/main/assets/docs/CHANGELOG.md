## [4.0.0] - 2026-07-14

### 🎉 重大重构：Kotlin + Jetpack Compose 全面升级

这是 UIN Tool 发展史上最重要的一次重构，整个应用从技术栈到架构都进行了全面升级。

---

### 🚀 技术栈全面升级

#### 编程语言迁移

- **Kotlin 全面迁移**：核心代码从 Java 迁移到 Kotlin
  - 134 个 Kotlin 文件，39 个 Java 文件
  - 利用 Kotlin 空安全、协程、扩展函数等特性
  - 代码量减少约 30%，可读性大幅提升
- **Java 遗留保留**：Termux 终端核心保留 Java 实现

#### UI 框架重构

- **Jetpack Compose**：从 XML 布局全面迁移到声明式 UI
  - 采用 Compose 2024.09.00 BOM
  - Material 3 设计语言
  - 响应式 UI 更新，无需手动管理 View 状态
- **ViewBinding 保留**：部分复杂界面保留 ViewBinding 支持
- **Compose 组件库**：40+ 可复用 Compose 组件

#### 架构重构

- **MVVM 架构**：引入 ViewModel + StateFlow 响应式状态管理
  - 9 个 ViewModel 覆盖所有主要页面
  - 单向数据流，状态可预测
- **Repository 模式**：数据层与业务层分离
  - `IConfigRepository`：配置管理接口
  - `IPluginRepository`：插件管理接口
  - `BackupRepository`：备份管理接口
- **依赖注入**：ServiceLocator 统一管理服务实例
  - 单例模式管理核心服务
  - 延迟初始化，优化启动性能
- **分层架构**：UI → ViewModel → Repository → DataSource
  - 清晰的职责划分
  - 便于单元测试和维护

## [3.10.0] - 2026-06-09

### 🎉 重大更新：GitHub 加速 + 强制更新机制

#### GitHub 加速功能

- **镜像站管理**：独立的 GitHub 加速管理页面
  - 内置 13+ 个国内可用镜像站
  - 支持手动添加自定义镜像站
  - 支持导入/导出镜像站列表（txt 格式）
  - 支持一键测试镜像站可用性
  - 镜像站列表支持全选/取消全选
  - 长按可删除自定义镜像站

- **CDN 加速**：可开关的 CDN 代理加速下载
  - 开启后使用 CDN 代理加速文件下载
  - 关闭后直接使用原始 GitHub 地址

- **镜像站配置文件**：`assets/Github_Mirrors.txt`
  - 格式：`名称|URL|备注`
  - 支持注释（以 `#` 开头）

#### 强制更新机制

- **Release Tag 格式**：`{versionCode}-{versionName}-{forceFlag}`
  - `forceFlag = 1`：强制更新（用户无法跳过）
  - `forceFlag = 0` 或无：普通更新（用户可跳过）

- **强制更新特点**：
  - 更新弹窗中「暂不更新」按钮被隐藏
  - 用户必须选择「自动下载」或「手动下载」
  - 适用于严重 Bug 修复或安全更新

#### 修复

- **修复 SplashActivity 崩溃**：
  - 修复 Activity 销毁后尝试显示 Dialog 导致的 `BadTokenException`
  - 添加 Activity 生命周期检查，确保 Dialog 安全显示
  - 添加 `safeShowDialog()` 和 `safeDismissDialog()` 方法

- **修复 CheckBox 背景变色问题**：
  - 统一 CheckBox 样式，设置 `buttonTint` 和透明背景
  - CDN 加速开关改用 TextView 状态显示，彻底解决背景变色
  - 修复 UI 配置页面图标着色开关背景问题

- **修复权限管理页面 CheckBox 背景**：
  - 统一 CheckBox 样式，与整体 UI 保持一致
  - 设置 `clickable="false"` 和 `focusable="false"`

- **修复布局文件编译错误**：
  - 修复 `activity_github_mirror.xml` 中的 XML 语法错误
  - 修复资源引用问题

#### 优化

- 镜像站列表支持全选/取消全选
- 整体页面滑动优化，镜像站列表独立滑动
- 更新文档完善，记录所有功能
- 优化 RecyclerView 滑动性能

## 升级指南

### 从 v3.x 升级到 v4.0.0

v4.0.0 是一次重大重构，升级前请注意：

1. **UI 完全重写**：基于 Compose 的全新 UI，交互方式有变化
2. **配置不兼容**：旧版 UI 配置需要重新设置
3. **插件兼容**：插件系统保持向后兼容
4. **终端功能增强**：基于 Termux 的完整终端体验

### 从 v2.x 升级到 v3.x

1. **备份数据**：建议先备份插件和配置
2. **重新安装**：建议卸载旧版后重新安装
3. **权限重新授予**：新版可能需要重新授予权限
