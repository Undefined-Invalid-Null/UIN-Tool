# UIN Tool 7.0.0

> 版本代码 27 · 2026-11-19 · 强制更新（Tag：`27-7.0.0-1`）

大版本更新：「文件」页全面启用，系统「打开方式」合并为单一入口；代码编辑器、文档阅读、桌面小部件、容器管理与整体界面同步升级。

## 文件管理

- **双窗格文件管理器**：前进 / 后退 / 上一级，多选与区间选择，复制 / 移动 / 删除 / 重命名 / 新建，撞名三选（可全部应用），可取消的分层进度，回收站与后台任务
- **归档就地浏览与写入**：zip / 7z / tar，以及 gzip、bzip2、xz、zstd 外层压缩；按魔数识别真实格式，改错后缀也能打开。zip 支持新增 / 覆盖 / 改名，兼容 AES-256 与分卷
- **内置查看器**：图片（缩放 / 翻页 / GIF）、APK 信息、字体、十六进制、密钥库；任意两个文件或目录可并排对比
- **批量重命名**（正则 / 模板编号 / 大小写）、文件管理设置、远程管理（FTP / HTTP）、提取安装包

## 打开方式

- 系统「打开方式」合并为**一个**入口：内置能力网格 + 插件列表 + 系统候选，一次看全，每个后缀都能设默认
- 新增 `uin://files` 深链，浏览器点开直达文件页并定位到目标

## 代码编辑器

- 全文搜索改为整页结果视图，支持「在结果中搜索」与确定进度；新增 9 种内置语法（语法清单 96 → 105）
- 二进制 AXML 可直接编辑并按二进制保存；文件被外部改动时提示重新加载

## 文档阅读

- Markdown 渲染改用 commonmark + GFM 表格，标题锚点与手写目录恢复可用；目录侧边栏可逐级收拢

## 小部件与容器

- 桌面小部件：3x3 改为可搜索多选列表（最多 9 格，勾选顺序即格位），1x1 改为可搜索单选
- 容器导入 / 导出改走内置文件选择器，rootfs 拷贝移到 IO 线程，导入页不再卡死

## 插件

- 插件权限管理改为两级页面：先选插件（列表直接显示「已授权 n/m」），再看它的权限清单，可一键全部授权 / 撤销
- 压缩解压插件可直接读写共享存储里的原路径

## 界面与交互

- 新拟态统一到按钮、下拉、弹窗、提示与底栏；新增「默认启动页」与底部 tab 排序
- 风格系统按风格隔离配置：深浅色 / 风格切换不再把一套风格的渐变写进另一套
- 启动页只在首次启动、升级后、缺存储权限三种情况出现

## 升级说明

- 支持 Android 6.0 及以上
- **本版换了签名密钥**：从旧版覆盖安装会被系统拒绝（提示「应用未安装」或签名不一致），需先卸载旧版再安装；卸载会清除应用数据，请提前备份
- 首次启动会展示本页更新说明，之后可在「管理 → 文档中心 → 更新日志」查看完整记录
- 构建链同步升级：compileSdk 37、AGP 9.1.1、Gradle 9.3.1、Kotlin 2.4.21
